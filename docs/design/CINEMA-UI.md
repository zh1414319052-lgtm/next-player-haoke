## 行为约束

新安装默认深色、固定青绿色、视频模式；用户已经保存的主题、动态色及媒体视图选择继续生效。续播入口和自动播放队列保留。进度按真实 0–1 比例绘制，完成或越界时限制在轨道内。

片头片尾仍使用原有全局时长和开关：关闭保留数值；输入后保存生效；取消不保存；原边界规则、撤销、回看与循环保护不变。默认倍速弹窗为即时保存，关闭按钮不承诺撤销。插帧沿用播放服务和状态判断，从播放器控制栏进入。

默认字幕基线根据实际布局避让：竖屏预留完整底栏，横屏预留进度条与操作栏，在时间行的中间区域显示字幕；横屏中间播放键同时上移，为两行字幕留出空间。控制栏隐藏、锁定或进入画中画时恢复原默认；保留作者显式指定的字幕行位置。窗口高度变化重新测量，极小视口最多预留一半高度。字幕内容、轨道与解码不被改写。

未获得权限时不自动弹出请求，显示说明、授权和打开设置；未授权内容继续受原权限条件约束。没有扩大权限或修改网络访问门控。该部分只做了相关门控追踪与正常交互验证，不是完整安全审计。

## 交互与动效

预览串联媒体库 → 播放 → 返回，以及更多 → 设置 → 播放设置 → 自定义跳过/默认倍速。预览转场 220ms，退出弹窗 140ms，支持减少动态效果。网页保存、撤销、重做已实际验证。

原生采用现有导航生命周期和 Material 3 动效，播放控件淡入淡出；按钮最小触控区域 48dp。没有增加循环装饰动效或额外后台任务。网页预览不替代真实解码、权限、持久化和设备交互验收。

当前正式版本为 `0.19.0-haoke.6 (81)`，沿用既有正式包名和签名；对应测试结果及发布记录见软件根目录唯一的 `交付说明.md`。原 QA 与过程截图、旧导出已收敛清理，正式包已在真机验证。未覆盖多机型、完整 15 分钟连续播放、真实电视投屏和平板分屏。
